# 04｜P3：香港入口节点小流量 A/B 实验

- **类型：**基础设施实验方案 + 运维待办；不是“直接上线方案”
- **优先级：**P3；依赖 [01 可观测性](01-observability-design.md)，与 P1/P2 结论共同解释
- **状态：**提案；没有新建云资源或迁流授权

## 1. 假设与边界

假设 H1：对一部分中国大陆客户，香港入口相较新加坡入口可降低入口建连/传输故障。H2：入口改善未必降低上游 502/503 或 TTFT。H3：香港转发到新加坡会新增一段链路，未证明优于区域独立入口前不采用串联架构。

当前缺客户地区/运营商同期对照，所以香港有效性未知。云地域标签不等于客户路由质量。

## 2. 实验设计

- **对照组：**现有新加坡入口。
- **实验组：**独立香港入口，尽量部署相同应用版本、Caddy版本、关键配置、资源与依赖路径；记录无法一致的差异。
- **分配：**先由可识别的自愿测试客户或明确可回滚的 DNS/路由策略进入；避免同一客户端频繁在 region 间切换导致连接池混淆。保留稳定分组标记，不在指标 label 放客户身份。
- **流量阶段：**仅合成/内部 → 指定测试客户 → 经批准的低比例 → 逐步扩大。阶段百分比由业务负责人依据流量与风险决定，不由文档臆定。
- **网络拓扑：**首选每个地区入口直接连接同一上游策略；若香港与新加坡后端/数据不同，必须纳入实验变量。不能拿“香港入口再转新加坡”结果冒充香港直连上游表现。

## 3. 指标与采样

按同一时间窗、接口协议、模型/上游类别、请求大小与流式属性比较：
- TCP 建连、TLS 握手及首响应（客户端侧可测时）；
- P50/P95/P99 TTFT、最大 chunk gap、完整时长；
- 成功率、客户端主动取消率、下游写失败/超时率；
- 上游 connect/first-byte 时延、502/503、每请求重试/切换次数；
- region 实例 CPU、内存、网络吞吐、连接数、丢包/重传（仅在有窗口基线时解释）。

报告样本量、观察时段、客户区域/运营商分布、协议分布、置信区间或适当的不确定性说明。小样本不得宣称统计显著。客户侧网络测量应获同意、最小化采集，不保存不必要的公网 IP。

## 4. 成功/停止标准

实验启动前，负责人填写并批准：
- 业务最小有意义改善幅度（按建连/错误率/TTFT 的目标指标分别定）；
- 观察时长与最低有效样本量；
- 最大可接受错误率、P95/P99 回归、资源与成本上限；
- 触发立即停止/回滚的阈值和 on-call 负责人。

若客户入口指标改善而 upstream 错误/TTFT 不变，结论限定为“入口路径改善，端到端根因仍包含上游/应用因素”。若无改善或长尾变差，停止扩流；不得以总体均值掩盖某 ISP 恶化。

## 5. 实施待办与退出

- [ ] 选定候选云服务/网络方案并核对价格、带宽、合规、可用区、IP 与 TLS/DNS 方案。
- [ ] 设计区域部署/配置同步/证书/密钥管理，不复制生产秘密到实验记录。
- [ ] 建立健康检查、入口选择、会话粘性与故障时退出策略；确认不会重复计费或改变 API Key 限制。
- [ ] 先跑合成探测与协议兼容矩阵，再开放指定用户。
- [ ] 记录成本与资源；定义节点删除/停止服务、DNS 撤回、证书和密钥清理步骤。
- [ ] 实验结束后提交带原始聚合数据（脱敏）、结论、置信度、成本和建议的报告；决定继续、改拓扑或撤销。

## 6. 安全边界

不直接修改当前生产 DNS、防火墙、Caddy、流量权重或云资源。任何创建资源、产生费用、改变用户流量的动作都需单独明确授权。测试不得压测真实上游或绕过限流。
