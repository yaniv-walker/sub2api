# 前端联调接口契约

2026-10-01 · v1 · 静态访客读取和本机管理接口。

## 接口映射

| 接口 | 方法 | 返回 | 说明 |
|---|---|---|---|
| `/homepage/config.json` | GET | 原始 PublicSnapshot | 本地由配置服务提供；生产由 Caddy 文件服务提供 |
| `/admin-api/state` | GET | `{data:State,source:fixture/live}` | 本地读取草稿/发布/历史 |
| `/admin-api/draft` | PUT | `{data:State}` | `{expected_revision,config}` 保存完整草稿 |
| `/admin-api/validate` | POST | `{data:Config}` | `{config}` 校验不写入 |
| `/admin-api/publish` | POST | `{data:State}` | `{expected_revision}` 发布已保存草稿 |
| `/admin-api/restore` | POST | `{data:State}` | `{expected_revision,revision}` 历史恢复为草稿 |
| `/admin-api/export` | POST | `{data:{id,revision,path}}` | `{}` 导出当前发布静态目录 |
| `/admin-api/candidates` | GET | `{data:Model[],source,observed_at}` | 匿名公开模型候选；默认 fixture |
| `/api/v1/settings/public` | GET | Sub2API Envelope | 本地 fixture 或 live GET，生产原样反代 |
| `/api/v1/model-plaza` | GET | Sub2API Envelope | 本地 fixture 或 live GET，生产原样反代 |

`/admin-api/*` 不是 Sub2API 已存在的 API，也不会部署到 Caddy 静态包。管理服务仅监听 127.0.0.1。

## 数据类型

```typescript
type Action = {id:string;label:string;href:string;enabled:boolean;variant:'primary'|'secondary'|'text'};
type Model = {id:string;label:string;category:'text'|'code'|'image'|'video';enabled:boolean};
type Config = {
  schema_version:1;
  brand:{name:string;logo_text:string;logo_url:string};
  hero:{badge:string;title:string;accent:string;description:string};
  navigation:Action[];
  actions:Action[];
  api:{enabled:boolean;base_url:string;label:string;hint:string;copy_enabled:boolean};
  models:{enabled:boolean;title:string;description:string;observed_at:string;items:Model[]};
  capabilities:{id:string;icon:'layers'|'key'|'shield'|'bolt'|'globe'|'chart';title:string;description:string;enabled:boolean}[];
  announcement:{enabled:boolean;id:string;version:number;title:string;date:string;body:string;
    mode:'popup'|'banner'|'silent';policy:'visit'|'daily'|'once';starts_at:string|null;ends_at:string|null;actions:Action[]};
  footer:{copyright:string;links:Action[]};
  runtime:{system_settings:boolean};
};
type Version = {revision:number;published_at:string;config:Config};
type PublicSnapshot = Version & {schema_version:1};
type State = {schema_version:1;draft_revision:number;draft:Config;published:Version;history:Version[]};
```

完整示例：`public/homepage/config.json`。配置更新必须发送完整文档，未知字段拒绝；`Config` 内不保存秘密。

公开快照仅返回启用条目。停用公告的正文被清空；schema 仍完整，便于公共前端校验。草稿内容、历史版本和操作者不出现在公共配置中。

## 请求/错误约定

写入 `Content-Type: application/json`；浏览器同源 fetch 自动带 Origin，配置服务要求 Origin 与当前本机 Host 一致。Host 仅 localhost/127.0.0.1+实际监听端口，限制 DNS rebinding。默认没有公共 CORS。

```json
{"expected_revision":3,"config":{"schema_version":1,"...":"以完整示例替代"}}
```

```json
{"error":{"code":"CONFIG_REVISION_CONFLICT","message":"草稿已被其他操作更新，请重新载入"}}
```

| HTTP | code | 前端动作 |
|---|---|---|
| 400 | REQUEST_FAILED | JSON 无效，提示修正 |
| 403 | INVALID_HOST / INVALID_ORIGIN / ORIGIN_REQUIRED | 检查本机来源，不尝试绕过 |
| 404 | NOT_FOUND / VERSION_NOT_FOUND | 提示未找到，不清空现有配置 |
| 409 | CONFIG_REVISION_CONFLICT | 先保留当前表单或下载 JSON，再重载最新草稿 |
| 413/415 | REQUEST_FAILED | 限制大小或检查内容类型 |
| 422 | VALIDATION_ERROR | 显示字段路径，例如 `api.base_url` |
| 500 | REQUEST_FAILED | 操作失败；旧发布快照保留 |

公共配置支持 ETag 条件 GET。本地使用 JSON 内容哈希，Caddy file_server 使用自身文件 ETag；消费者不解析 ETag 内部格式。配置/稳定文件名均 `Cache-Control:no-cache`，避免发布后仍长时间读旧资源。

## Sub2API 适配

公开设置必须先取 `.data`，不能把 Envelope 当业务对象。前端只选择 `site_name`、安全 `api_base_url`、`registration_enabled`，不遍历渲染整个响应。开启 `system_settings` 后失败保留发布快照，提示地址使用快照。

模型广场 `.data.groups[].models[].name` 只提取名称；`is_exclusive` 必须严格等于 false，任何专属或形态不明分组不导入。去重最多 200 项；不从名字推断真实 text/image/code 能力，分类默认 text 由管理员手动确认。后台显示 fixture/live 来源，不把示例结果称为线上结果。首页不自动轮询模型源，也不访问带 API Key 的 `/v1/models`。

## 草稿预览

工作台通过一次性 UUID 的 BroadcastChannel 发送已经验证的内存配置到同源预览页；等待握手再发送，超时关闭。预览页有明确未发布横幅，没有读取草稿 API。静态生产首页没有工作台窗口时，伪造 `?preview=` 只会显示超时提示。

## UI Bridge 后续契约

当前宿主已定义以下信封，但本工程尚未打成可安装的普通配置插件：

```json
{"source":"sub2api-plugin-ui","bridge_token":"短时 fragment token","type":"config.load","request_id":"唯一 ID"}
```

后续适配：`config.load` → 加载完整 State 文档；`config.save` → 保存文档并由运行时验证；`plugin.status` → 只读状态。接收必须检查 `event.source===parent`、消息 source、bridge_token、request_id，设置超时及卸载清理。不可用 `config.test` 代替只读状态，也不自创 `config.publish` 消息宣称宿主已支持。

发布动作可由插件内 document 的 draft/published 变化表达，校验器验证 revision 与历史；但多进程版本条件保存需宿主 CAS 或独占写者，普通 `config.save` 本身不保证完整的跨实例乐观锁。静态导出必须由服务器/运维工具完成，不能让 iframe 浏览器读取私钥或写生产目录。

当前清单阻碍、导出端口、沙箱 CSP（connect-src:none）与上述 localhost HTTP 服务不同，是接入阶段需解决的明确条件。独立工作台可先正常配置和导出。
