# 模型广场与统一官方价格

## 使用方式

- 在「渠道定价 → 官方价格维护」选择平台，搜索/新增模型并维护参考价格。
- Token 输入单位为美元/百万 tokens，后端存储单位为美元/token；按次、按张字段使用原单位。
- 字段留空继续自动获取，填写 0 表示明确零价。「恢复自动获取」只清除该模型人工覆盖。
- 官方长上下文/媒体阶梯支持自动回落、整表替换、显式清空；人工数据不会被自动价格目录刷新覆盖。
- 模型广场访问 `/model-square` 或原 `/model-plaza`，原首页、后台和内嵌入口仍可用。
- 账号新增、编辑、批量保存、导入成功后，后端排队更新支持模型。无需逐条维护广场模型与分组绑定。
- 新广场支持厂商目录、模型卡片与列表、搜索、分组筛选、价格排序、复制模型 ID、分组清单及价格详情。

## 价格边界

人工官方价格是全局参考覆盖，按真实平台和规范化模型 ID 隔离。渠道「获取默认价格」和广场共用覆盖服务。

只修改基础单价、阶梯仍选自动获取时，继承原阶梯相对于基础价的比例，参考表与广场报价保持一致；选择手工阶梯时按整套绝对价格替换。

广场未显式定价字段优先读取人工维护值，缺项沿用原目录/内置回落。渠道、分组已有显式售价保持优先；人工官方价不会自动重写这些售价，也不改变网关实际扣费。

分组/用户倍率、图片视频独立倍率、分时、长上下文及固定价的既有应用逻辑保留。广场选择报价时使用一个实际支持该模型的可见分组，不把不同分组的低价拼接为虚构报价。

## 自动模型发现

账号完整保存产生带 `model_catalog_sync` 的持久化 scheduler outbox 事件；分组关联事件也会触发排队。配额、使用量、常规 Token 观察事件不触发模型拉取。

后台队列合并重复账号任务，独立执行模型发现并设置超时。保持账号身份供 OAuth 缓存隔离，但使用只读发现上下文禁止现有同步流程在条件更新前保存元数据。

模型快照保存在 `accounts.extra.model_square_catalog`，含模型列表、配置版本、最近尝试/成功时间和状态。写入比较账号配置版本与旧快照；迟到结果不能覆盖新配置或新快照。快照写入不修改配置更新时间、不生成新 outbox 事件，避免递归同步。

失败或超时保留最后成功列表，并记录通用错误码，不保存凭据或原始上游错误。服务启动时补同步缺失、失败或配置变更的快照。首次发现前使用已有账号映射、已知元数据和平台本地默认列表回落；全局价格目录不代表账号支持。

广场查询按当前活跃、可调度账号的分组关系聚合，应用账号映射、渠道映射/模型限制和平台隔离；移组、禁用、删除后的关系随查询更新。多个账号支持同一模型时取并集。

此支持列表是发现结果与配置交集，不是实时健康保证。同步失败后可能暂时展示最后成功结果。

## 管理 API

```text
GET    /api/v1/admin/channels/pricing/official?platform=&search=&limit=
GET    /api/v1/admin/channels/pricing/official/model?platform=&model=
PUT    /api/v1/admin/channels/pricing/official/model?platform=&model=
DELETE /api/v1/admin/channels/pricing/official/model?platform=&model=
```

单模型 PUT 替换该模型的人工覆盖文档；价格可为 null，阶梯 null 为继承、[] 为清空。逐模型 settings 行隔离，保存一个模型不会覆盖其他模型。对同一个模型同时编辑时采用后保存的文档；前端保留未保存离开提醒。

列表最多返回 200 项，超出时搜索缩小范围。管理接口沿用现有认证、审计与限流；用户广场仍使用原可选登录及公开/专属/订阅权限过滤，不返回账号快照或凭据。
