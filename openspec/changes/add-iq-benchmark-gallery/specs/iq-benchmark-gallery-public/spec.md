## ADDED Requirements

### Requirement: 作品展必须对普通用户公开但强制登录

系统 MUST 提供作品展只读页面与配套只读接口。所有只读接口 MUST 要求已认证用户身份；未认证请求 MUST 被拒绝且 MUST 引导前端跳转登录页并在登录后回到原目标路径。管理员 MUST 额外具备题目、任务、执行记录、产出与配置的管理能力。公开侧 MUST NOT 提供匿名访问入口、MUST NOT 提供站外分享链接。

#### Scenario: 未登录访问作品展

- **WHEN** 未认证用户直接访问作品展页面或其任一接口
- **THEN** 页面 MUST 跳转至登录页并携带原目标路径作为回跳参数
- **THEN** 接口 MUST 返回 401

#### Scenario: 已登录普通用户访问

- **WHEN** 已认证的普通用户访问作品展
- **THEN** 系统 MUST 返回只读数据
- **THEN** MUST NOT 返回任何管理操作入口或管理字段

#### Scenario: 管理员访问公开视图

- **WHEN** 管理员访问作品的公开视图
- **THEN** 其可见字段 MUST 与普通用户一致（管理字段仅在管理视图可见）

### Requirement: 作品展必须提供双页签视图

作品展 MUST 提供至少两个页签：图片作品（对应 `render_kind` 为图片类）与题目问答作品（对应文本类）。页签切换 MUST NOT 重新拉取全部数据导致状态丢失；筛选条件 MUST 在页签切换后保持。

#### Scenario: 切换到图片页签

- **WHEN** 用户选择图片页签
- **THEN** 列表 MUST 只包含图片类作品

#### Scenario: 页签切换保持筛选

- **WHEN** 用户先设置分组与模型筛选，再切换页签
- **THEN** 已设置的筛选条件 MUST 保持生效

### Requirement: 列表必须支持分页、筛选与稳定排序

只读作品列表 MUST 支持分页、按分组、按模型、按题目、按时间范围、按状态筛选。分页参数 MUST 有上限：单页条数上限 MUST 为 50，超过上限的请求 MUST 以 400 状态码拒绝而非静默截断。默认排序 MUST 为 `created_at` 降序，相同时 MUST 以 `id` 降序保证稳定。

#### Scenario: 请求超过单页上限

- **WHEN** 请求携带 `page_size = 51`
- **THEN** 系统 MUST 返回 400 并带稳定错误码
- **THEN** 系统 MUST NOT 返回被静默截断的结果

#### Scenario: 请求边界值

- **WHEN** 请求携带 `page_size = 50`
- **THEN** 系统 MUST 正常返回

#### Scenario: 组合筛选

- **WHEN** 请求同时携带分组、模型与时间范围
- **THEN** 返回结果 MUST 同时满足全部条件

#### Scenario: 排序稳定

- **WHEN** 存在多条 `created_at` 完全相同的产出
- **THEN** 分页结果的顺序 MUST 在多次请求间保持一致

### Requirement: 公开响应必须使用字段白名单

公开侧所有响应 MUST 使用独立的公开数据结构，MUST NOT 直接序列化管理端结构或复用管理端字段集合。公开响应 MUST NOT 包含以下任一项：内部账号标识、API Key 标识、账号 ID、上游渠道或供应商信息、请求/响应头、堆栈信息、原始响应引用、危险构造标记列表、内部错误码。成本与 token 数 MUST 默认不下发，仅在配置显式开启时下发。错误信息 MUST 只下发脱敏摘要。

#### Scenario: 公开响应不含内部标识

- **WHEN** 任意公开接口返回作品数据
- **THEN** 响应 MUST NOT 包含内部账号标识、API Key 标识或账号 ID

#### Scenario: 公开响应不含成本

- **WHEN** 配置中「向用户展示成本」为关闭（默认）
- **THEN** 公开响应 MUST NOT 包含任何成本字段

#### Scenario: 开启成本展示

- **WHEN** 配置中「向用户展示成本」被显式开启
- **THEN** 公开响应 MUST 只包含该条作品自身的成本数值
- **AND** MUST NOT 包含成本构成明细

#### Scenario: 公开响应不含堆栈与内部错误码

- **WHEN** 某条产出处于失败状态
- **THEN** 公开响应 MUST 只包含脱敏后的状态摘要
- **AND** MUST NOT 包含堆栈、上游错误原文或内部错误码

#### Scenario: 白名单由测试断言

- **WHEN** 运行后端单元测试
- **THEN** MUST 存在一个测试遍历公开数据结构字段并断言禁止字段不在其中

### Requirement: 内容渲染必须经消毒且禁止未消毒直出

系统 MUST 将模型输出视为不可信内容。SVG 与 HTML 内容 MUST 在入库前接受服务端静态扫描，识别并标记危险构造（脚本标签、事件处理属性、`foreignObject`、`javascript:` 协议、实体声明、`DOCTYPE`、`iframe`/`object`/`embed`、CSS `@import`、`data:` URI、指向外部资源的引用）。命中阻断类构造的内容 MUST 被标记为被拦截状态；命中可剥离类构造的内容 MUST 剥离后再入库。前端 MUST 在渲染前再次执行消毒，且 MUST NOT 通过未消毒的原始 HTML 注入方式渲染任何模型输出。图片类内容 MUST 优先以图片元素引用对象存储地址渲染，以避免脚本执行。

#### Scenario: 含脚本的输出

- **WHEN** 模型输出包含 `<script>` 标签
- **THEN** 该产出 MUST 被标记为被拦截状态
- **THEN** 公开响应 MUST NOT 下发其内容正文

#### Scenario: 含事件处理属性

- **WHEN** 模型输出包含 `onload=` 之类的事件处理属性
- **THEN** 系统 MUST 剥离该属性后再入库
- **THEN** 入库的正文 MUST NOT 再包含该属性

#### Scenario: 含外部资源引用

- **WHEN** 模型输出的 SVG 包含指向外部主机的引用
- **THEN** 系统 MUST 剥离该引用
- **THEN** 系统 MUST 记录相应标记

#### Scenario: 前端渲染消毒

- **WHEN** 前端渲染任何 SVG 或 HTML 内容
- **THEN** 渲染前 MUST 经过消毒函数处理
- **AND** MUST 存在测试断言未消毒的危险输入不会进入 DOM

#### Scenario: 图片优先以图片元素渲染

- **WHEN** 作品的 `render_kind` 为图片地址
- **THEN** 前端 MUST 以图片元素引用该地址渲染

### Requirement: 失败作品必须入库并可见

系统 MUST 将失败、超时与被拦截的检测结果同样持久化为产出记录，MUST 记录其状态与脱敏错误摘要。作品展 MUST 以占位卡片展示这些产出并显示状态角标。系统 MUST NOT 因失败而跳过该条记录。

#### Scenario: 超时产出

- **WHEN** 一道题目执行超时
- **THEN** 系统 MUST 写入一条状态为超时的产出
- **THEN** 作品展 MUST 显示占位卡片与超时角标

#### Scenario: 被拦截产出

- **WHEN** 一道题目的输出被内容审核拦截
- **THEN** 系统 MUST 写入一条被拦截状态的产出
- **THEN** 公开响应 MUST NOT 下发其正文内容

#### Scenario: 失败产出计数

- **WHEN** 一次执行包含 2 条成功与 1 条失败产出
- **THEN** run 的汇总计数 MUST 准确反映 2 成功 1 失败

### Requirement: 详情与横向对比必须可用

系统 MUST 提供单条作品详情查看，包含题面快照、执行时间、耗时、状态与评分（若有）。系统 MUST 提供同题多模型的横向对比视图，按题目维度对齐不同模型的产出。详情与对比 MUST NOT 泄露超出白名单范围的字段。

#### Scenario: 查看详情

- **WHEN** 用户点击一条作品
- **THEN** 系统 MUST 返回该作品的题面快照与基本指标
- **THEN** 响应 MUST 符合公开白名单

#### Scenario: 同题横向对比

- **WHEN** 用户选择某道题目与多个模型进行对比
- **THEN** 系统 MUST 按题目对齐展示这些模型的产出

#### Scenario: 查看不存在的作品

- **WHEN** 用户请求一个不存在或已清理的作品 ID
- **THEN** 系统 MUST 返回 404

### Requirement: 功能未启用时用户侧必须不可达

当功能开关为 `enabled = false`（默认值）时，用户侧作品展路由 MUST 不可达：导航入口 MUST 隐藏、直接访问路由 MUST 返回未启用状态、全部用户侧接口 MUST 返回 404、限流中间件 MUST NOT 参与。管理员侧除读取与写入配置的接口外，其余接口 MUST 返回明确的「未启用」错误（503 + 稳定错误码）。

#### Scenario: 未启用时直接访问用户路由

- **WHEN** 功能未启用且用户直接访问作品展路由
- **THEN** 页面 MUST 显示未启用状态
- **THEN** 接口 MUST 返回 404

#### Scenario: 未启用时调用管理员功能接口

- **WHEN** 功能未启用且管理员调用题目或任务接口
- **THEN** 系统 MUST 返回 503 与稳定错误码「未启用」
- **THEN** 消息 MUST 明确提示「功能未启用」

#### Scenario: 未启用时仅配置接口可用

- **WHEN** 功能未启用
- **THEN** 管理员读取与写入配置的接口 MUST 保持可用
- **THEN** 写入后 MUST 能使功能即时生效而无需重启服务

#### Scenario: 未启用时零副作用

- **WHEN** 功能未启用且服务运行一段时间
- **THEN** 本功能的 4 张表 MUST 保持零行
- **THEN** MUST NOT 产生任何出站模型调用

### Requirement: 产出能力必须受容量上限约束

系统 MUST 对单次执行的文件大小、文件数量、全局保留条数与保留天数提供配置化上限。超过单文件上限的响应 MUST 被截断并记录截断标记。超过单次执行产出数量上限时 MUST 截断并记录。系统 MUST 提供周期性清理：按保留天数与保留条数删除产出，并在清理后同步清理执行记录。当未删除产出数超过配置上限的 1.2 倍时，系统 MUST 拒绝写入新产出并告警。

#### Scenario: 单文件超限

- **WHEN** 模型返回的单个图片超过配置的单文件上限
- **THEN** 系统 MUST 截断并写入截断标记
- **THEN** 该产出 MUST 状态为失败或被标记为已截断

#### Scenario: 单次执行产出超量

- **WHEN** 一次执行产生的产出数量超过配置上限
- **THEN** 系统 MUST 只保留上限内的数量并记录被截断数量

#### Scenario: 按保留天数清理

- **WHEN** 存在超过保留天数的产出
- **THEN** 周期清理 MUST 移除这些产出
- **THEN** 其所属执行记录在全部产出清理后 MUST 一并清理

#### Scenario: 超过容量硬上限

- **WHEN** 未删除产出数超过配置上限的 1.2 倍
- **THEN** 系统 MUST 拒绝写入新产出并告警

#### Scenario: 清理单实例执行

- **WHEN** 多实例部署同时到达清理时刻
- **THEN** 清理 MUST 只由一个实例执行
